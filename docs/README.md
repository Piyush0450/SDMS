# 🖼️ SDMS Documentation Screenshots Guide

This directory contains visual assets and screenshots demonstrating the features and interface of the **Student Data Management System (SDMS)**.

---

## 📂 Screenshot Location & File Naming Conventions

Place all screenshot image files inside the `docs/screenshots/` folder.

### Recommended File Names

| Interface / View | Recommended Image Filename |
| :--- | :--- |
| **Login Page** | `login.png` |
| **Super Admin Dashboard** | `dashboard-superadmin.png` |
| **Admin Dashboard** | `dashboard-admin.png` |
| **Faculty Dashboard** | `dashboard-faculty.png` |
| **Student Dashboard** | `dashboard-student.png` |
| **User Management Table** | `user-management.png` |
| **Analytics & Reports** | `analytics-reports.png` |
| **Mobile View (Capacitor)**| `mobile-app.png` |

---

## 🔗 How to Link Screenshots in Main `README.md`

Use standard GitHub Markdown image embedding syntax in the main [`README.md`](../README.md):

```markdown
### Admin Dashboard Preview
![Admin Dashboard](docs/screenshots/dashboard-admin.png)

### Student Analytics & Results
![Student Results](docs/screenshots/dashboard-student.png)
```

To display multiple screenshots in a grid or table inside `README.md`:

```markdown
| Admin View | Student View |
| :---: | :---: |
| ![Admin Dashboard](docs/screenshots/dashboard-admin.png) | ![Student View](docs/screenshots/dashboard-student.png) |
```
